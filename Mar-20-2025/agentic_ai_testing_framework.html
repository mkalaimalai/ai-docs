01 — Evaluation Frameworks

Three-Layer Evaluation Model

McKinsey/QuantumBlack (Jan 2026) advocates a three-level model with increasing complexity. Each layer captures failures invisible to the layers below.

3

Multi-Agent System Evaluation

Inter-agent communication integrity, cascading failure detection, delegation correctness, and emergent behaviors from agent interactions.

2

Single Agent Evaluation

Tool selection accuracy, parameter generation, error recovery patterns, and reasoning coherence across multi-step execution.

1

LLM Evaluation

Factuality, calibration, robustness, and toxicity. Necessary but insufficient — doesn't validate tool use, memory, or multi-step action.

Four-Pillar Assessment Framework

Akshathala et al. (arXiv:2512.12791, Dec 2025) — validated in production CloudOps environments at MontyCloud.

🧠

LLM Pillar

Reasoning quality, factual accuracy, prompt adherence, hallucination detection, and chain-of-thought coherence.

💾

Memory Pillar

Single-hop recall, multi-hop retrieval, temporal reasoning, and open-domain retrieval combining conversational memory with external knowledge bases.

🔧

Tools Pillar

Tool selection accuracy, parameter fidelity, invocation sequencing, error handling and recovery, schema compliance.

🌐

Environment Pillar

Configurability, guardrails enforcement, security boundaries, fault injection resilience, cost and resource compliance.

Evaluation Metrics & Techniques

Core metrics for production agent evaluation, spanning task outcomes, tool quality, reasoning integrity, and safety compliance.

Harm Reduction Index, Guardrail Trigger Rate, Policy Violation Count
Safety

LLM-as-a-Judge

A separate LLM scores outputs against rubrics for factual accuracy, reasoning quality, and usefulness. NVIDIA/Lakera found 76.8% agreement with human labels. Used by StackAI, Maxim AI, LangSmith.

Trajectory Analysis

Examines each intermediate step in the observe-reason-act-reflect loop. Catches unsafe paths, unnecessary tools, and data exposure in intermediate steps that outcome-only metrics miss.

Human-in-the-Loop

Expert trace review for high-impact failures. A/B testing comparing versions on task success plus human-labeled helpfulness and clarity. Essential for qualitative dimensions.

04 — Security Guardrails

OWASP Top 10 for Agentic Applications

Released December 2025. Built by 100+ security researchers. Reviewed by NIST and European Commission representatives. The industry's primary agentic security taxonomy.

ASI01

Agent Goal Hijack

Attackers redirect agent objectives via instructions, tool outputs, or external content.

ASI02

Tool Misuse & Exploitation

Agents misuse legitimate tools due to prompt injection or unsafe delegation.

ASI03

Identity & Privilege Abuse

Exploiting inherited credentials, delegated permissions, or agent-to-agent trust.

ASI04

Supply Chain Vulnerabilities

Malicious tools, model descriptors, or MCP servers compromise execution.

ASI05

Unexpected Code Execution

Agents generate or execute attacker-controlled code in production.

ASI06

Memory & Context Poisoning

Persistent corruption of agent memory or RAG stores for flawed decisions.

ASI07

Inter-Agent Communication

Compromised messaging enables cascading manipulation across MAS.

ASI08

Cascading Failures

Single-point failures propagate through interconnected agent systems.

ASI09

Human-Agent Trust Exploitation

Abuse of human tendency to trust agent outputs without verification.

ASI10

Rogue Agents

Compromised or misaligned agents act as insider threats in production.

Defense-in-Depth: Four Planes

Production guardrails architecture recommended by Skywork AI, Authority Partners, and MIT Technology Review (2025–2026).

Execution Plane
Agents in gVisor/GKE Sandbox. Code-exec in Firecracker microVMs. WASI for plugin scoping. Network egress allowlists.
Data / Memory Plane
Vector stores on private subnets. PII redaction on ingestion and output. Scheduled memory TTLs and purges.
Observability Plane
OpenTelemetry GenAI spans. SIEM aggregation. SOAR automations for quarantine/revoke.
Assurance Plane
Sigstore/Cosign verification. SLSA attestations + SBOMs in CI/CD. Red-teaming cadence. EU AI Act / NIST mappings.

06 — Implementation

Building Your Framework: Three Phases

Evaluation-led development across the full SDLC — embed evaluation from day one with mandatory gates, regression alerts, and continuous monitoring.

01

Plan

  • Document agents using "Agent on a Page" template
  • Classify risk with AWS Scoping Matrix (1–4)
  • Select metrics per risk level from 4-pillar framework
  • Threat model with OWASP Multi-Agent Guide
  • Curate golden datasets with adversarial cases
02

Build

  • CI/CD gates blocking on TSR/faithfulness thresholds
  • LLM-as-a-Judge + trajectory analysis pipeline
  • Defense-in-depth guardrails across 4 planes
  • Deterministic controls over probabilistic LLM checks
  • Red team with NVIDIA Probes at each workflow node
03

Operate

  • Scheduled evals on production test sets
  • Track metric scores + drift over time
  • OpenTelemetry → SIEM → SOAR quarantine
  • Expert trace review for high-impact failures
  • Iterative red teaming from OWASP incident roundups
