2 Layer Breakdown

Static Layer

Source Code Structure

Parses repos into type-attributed trees. Resolves cross-file dependencies, generics, DI wiring, and interface implementations.

OpenRewrite LSTTree-sitterts-morphJoern CPGModerne CLI
Runtime Layer

Production Behavior

Captures actual service-to-service calls, latencies, error rates, throughput. Correlates spans to static code via code.function and service.name attributes.

OpenTelemetryJaegerFluent BitVectorGrafana Tempo
Infrastructure Layer

Deployment Topology

Maps cloud resources, networking, IAM, K8s workloads, and IaC definitions into the same graph. Bridges logical services to physical environments.

Terraform HCLKubernetes APIHelmCartographyAWS/GCP APIs
Knowledge Layer

Institutional Memory

Extracts patterns, standards, ADRs, post-mortems, and best practices from team channels. Enables the LLM to reason about intent, not just structure.

Slack APIConfluenceLLM extractionADR templatesGit commits
Query Layer

Hybrid Retrieval

Combines Cypher graph traversal with vector similarity search (GraphRAG). A single query can traverse code structure, check runtime metrics, and surface relevant patterns.

Neo4j CypherpgvectorLangChainLlamaIndextext2cypher
Agent Layer

LLM Orchestration

LLM agents use MCP tools to query the graph, reason over multi-layer context, and execute actions — code generation, review, refactoring, incident diagnosis.

Claude CodeMCP ServerOpenRewrite RecipesCustom Agents

5 Reference GitHub Projects by Layer

Static Layer — Code Graph Construction

STATIC · CODE GRAPH

ChrisRoyse/CodeGraph

Transforms codebases into Neo4j knowledge graphs. Multi-language support (TS, Python, Java, Go, Rust, C#). Two-pass AST analysis with cross-file relationship resolution. MCP integration for AI-powered queries via Cypher.
github.com/ChrisRoyse/CodeGraph
STATIC · GRAPHRAG

vitali87/code-graph-rag

Tree-sitter based parsing into Memgraph. MCP server for Claude Code. Semantic code search via UniXcoder embeddings. Pattern recognition and optimization workflows with interactive approval.
github.com/vitali87/code-graph-rag
STATIC · LST

openrewrite/rewrite

The OpenRewrite engine powering Lossless Semantic Trees. Full type attribution, format preservation, and 5000+ deterministic recipes. Foundation for Moderne's multi-repo AI agent (Moddy).
github.com/openrewrite/rewrite
STATIC · CPG

joernio/joern

Code Property Graph combining AST + Control Flow + Data Flow into a single supergraph. Supports C/C++, Java, Python, JS, and more. Queryable with Scala-based DSL for vulnerability detection and code understanding.
github.com/joernio/joern
STATIC · MULTI-AGENT

this-rs/project-orchestrator

Rust-based orchestrator: Neo4j code graph + Meilisearch semantic search + Tree-sitter for 16 languages. 22 MCP mega-tools for Claude Code. RFC lifecycle, knowledge fabric, multi-project workspaces.
github.com/this-rs/project-orchestrator
STATIC · MCP

optave/codegraph (npm)

Function-level dependency graph with sub-second incremental rebuilds. Tree-sitter → SQLite. 30 MCP tools for AI agents. Exports to Neo4j CSV, GraphML, Mermaid, DOT. Local embeddings via HuggingFace.
npmjs.com/package/@optave/codegraph

Runtime Layer — Traces, Logs, Observability

RUNTIME · TRACES

open-telemetry/opentelemetry-collector

CNCF graduated project. Vendor-neutral telemetry collection for traces, metrics, and logs. Auto-instrumentation for Spring Boot, Express, Django, and 100+ libraries. The standard pipeline for ingesting runtime data.
github.com/open-telemetry/opentelemetry-collector
RUNTIME · KNOWLEDGE GRAPH

Log2Graph (Paper)

Unifies logs, metrics, and traces into a Neo4j knowledge graph. LLM semantic parser achieves F1=0.91 for entity extraction. Natural language queries grounded in structured telemetry graph. 150GB/day at scale.
thesai.org — Log2Graph Paper
RUNTIME · LOGS

fluent/fluent-bit

High-performance log processor and forwarder. Parses, filters, and routes structured logs at scale. Output plugins for Elasticsearch, Kafka, and custom HTTP endpoints (for Neo4j ingestion via custom sink).
github.com/fluent/fluent-bit

Infrastructure Layer — Cloud, IaC, Topology

INFRA · CLOUD GRAPH

cartography-cncf/cartography

CNCF project. Consolidates AWS, GCP, Azure, K8s, GitHub, and 20+ data sources into a Neo4j graph. Exposes hidden infrastructure dependencies. Security posture analysis with attack path discovery.
github.com/cartography-cncf/cartography
INFRA · TEMPORAL GRAPH

Temporal Infrastructure KG (Blog)

Production Neo4j deployment modeling K8s, AWS, Terraform, and time as connected graph. Reconciles the same resource across Terraform code, Terraform state, and live cloud APIs. Cypher-based temporal traversal.
medium.com — Temporal Infra KG

Knowledge Layer — Patterns, Docs, Institutional Memory

KNOWLEDGE · GRAPH BUILDER

neo4j-labs/llm-graph-builder

Transforms unstructured data (PDFs, docs, web pages, YouTube) into structured Neo4j knowledge graphs using LLMs. Community summarization, parallel retrievers, and multi-model support. Perfect for ingesting Confluence, ADRs, and post-mortems.
github.com/neo4j-labs/llm-graph-builder
KNOWLEDGE · AGENT MEMORY

neo4j-labs/agent-memory

Graph-native memory for AI agents. Short-term (conversations), long-term (entity extraction), and reasoning traces. OpenTelemetry observability built-in. Integrations with LangChain, Pydantic AI, LlamaIndex, CrewAI.
github.com/neo4j-labs/agent-memory

Query & Agent Layer — MCP, GraphRAG, LLM Integration

AGENT · MCP

neo4j-contrib/mcp-neo4j

Official Neo4j MCP server. Provides read-neo4j-cypher (natural language → Cypher), write-neo4j-cypher, and get-neo4j-schema tools. The bridge between LLM agents and any Neo4j graph including Code Graphs.
github.com/neo4j-contrib/mcp-neo4j
AGENT · MULTI-REPO

Moderne / Moddy

Multi-repo AI agent combining LLMs with deterministic OpenRewrite recipes. LST-powered knowledge graphs for code search by business purpose. Tool-function calling to 5000+ recipes. Commercial, but architecturally instructive.
moderne.ai — Moddy Blog
AGENT · GRAPHRAG

CODEXGRAPH (NAACL 2025)

Academic framework: code graph databases as LLM agent interfaces. Primary agent writes natural language queries, translation agent converts to Cypher. Evaluated on CrossCodeEval, SWE-bench, and EvoCodeBench.
aclanthology.org — CODEXGRAPH
AGENT · HYBRID

stevereiner/flexible-graphrag

Full-stack GraphRAG: 8 graph DBs, 10 vector DBs, OpenTelemetry built-in, MCP server. Multi-source ingestion with hybrid search combining vector + full-text + graph traversal. Docker Compose deployment.
github.com/stevereiner/flexible-graphrag
